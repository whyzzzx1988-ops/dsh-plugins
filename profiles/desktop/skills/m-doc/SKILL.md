# m-doc · 文书 / 证件 / 合同 / 报告

被读到时：主人要写公文、合同、证明、简历、报告、模板。

## 一、公文骨架

```
标题（发文机关 + 事由 + 文种）
主送机关：
正文：缘由 → 事项 → 结语
附件：
发文机关署名
日期
```

语气：陈述句为主，不用第一人称，不写情绪词。数字用阿拉伯数字，层级用「一、（一）1. (1)」。

## 二、合同必备条款

1. 主体（名称、证件号、地址、联系方式）
2. 标的与范围
3. 价款与支付（时间、方式、账户、逾期条款）
4. 履行期限与验收标准
5. 违约与赔偿（比例、上限、计算方式）
6. 保密与知识产权归属
7. 争议解决（管辖法院 / 仲裁机构）
8. 生效条件与份数

缺口留 `【待填】`，不编造主体信息。

## 三、证明类模板

```
证 明

兹证明【姓名】，性别【】，身份证号【】，自【年】月【日】起
在【单位】担任【职务】，【在职/离职】状态。

特此证明。

【单位名称】（盖章）
【年】月【日】
```

要点：只写事实，不加评价；盖章位留空；日期用中文数字。

## 四、简历 / 自述

```
姓名 | 电话 | 邮箱 | 城市
一句话定位（做什么 + 几年 + 结果）
经历：公司 | 职位 | 时间 | 3 条 STAR（情境-任务-行动-结果，带数字）
项目：项目名 | 角色 | 技术栈 | 产出
技能：分「熟练 / 会用 / 了解」三档，别全写精通
```

## 五、报告

```
摘要（结论先行，3 行）
1 背景与目标
2 方法
3 发现（分条，每条带证据）
4 影响
5 建议（可执行，带优先级）
附录：数据、日志、截图
```

## 六、验收

结构齐、字段全、有占位符、日期与称谓一致。要 PDF/Word 就一并给生成脚本或 Markdown 源。
