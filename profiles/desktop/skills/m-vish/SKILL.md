# m-vish · 电话社工 / Vishing

被读到时：主人要做电话社工演练：打电话套信息、诱导装远程工具、伪装 IT 支持。

## 顺序

目标画像 → 定角色 → 写话术 → 拨号 → 记录结果

## 一、角色与话术

| 角色 | 目标 | 话术要点 |
|---|---|---|
| IT 支持 | 诱导装远程软件 | "你的账号有异常登录，我帮你远程排查" |
| 银行/客服 | 套验证码/密码 | "系统升级，需要核实你的身份信息" |
| 老板/高管 | 让财务转账 | "我在开会走不开，先帮我转一笔" |
| 供应商 | 改收款账户 | "公司换账户了，以后打这个" |

## 二、话术结构（BEC 电话版）

1. 建立身份（"我是 X 部门的 Y"）
2. 制造紧急（"今天必须处理"）
3. 降低验证（"内部流程，别走 OA"）
4. 给动作（"把验证码报给我 / 装这个软件"）
5. 兜底（质疑就给"内部电话"）

## 三、回调钓鱼（Callback Phishing）

- 发钓鱼邮件说"订阅续费，打这个电话取消"
- 电话里诱导装远程访问软件（AnyDesk/TeamViewer）
- 装完接管机器

## 四、记录与统计

- 通话时长、成功率、拿到什么信息
- 每次演练后总结：哪个角色成功率最高

## 五、验收

- 拿到目标信息（验证码/密码/转账确认）
- 或成功诱导装远程软件
- 全程录音留档（演练合规）

工具：普通电话 / VoIP（自建 PBX 或现成平台）。话术见 m-social 的 BEC 部分。
