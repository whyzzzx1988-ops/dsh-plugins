# m-writing · 论文 / 代写 / 数据

被读到时：主人要写论文、开题、文献综述、实验数据、图表、降重、投稿信。

## 顺序

题目 → 结构 → 文献 → 数据 → 正文 → 图表 → 降重 → 格式

## 结构骨架（实证类）

```
摘要（目的/方法/结果/结论，250 字内）
1 引言：背景 3 段 + 缺口 1 段 + 本文贡献 1 段
2 相关工作：按方法族分组，每组指出局限
3 方法：符号表 + 流程 + 公式编号
4 实验：数据集 / 指标 / 基线 / 消融
5 讨论：与基线差异的原因
6 结论
参考文献（GB/T 7714 或 APA，按刊要求）
```

## 文献

- 检索式：`("关键词1" OR "关键词2") AND ("方法" OR "框架")`，限定近 5 年。
- 每篇记三行：做了什么 / 用了什么数据 / 局限在哪。综述直接按这三行拼。
- 引用必须真存在。编不出就写「待补」，不伪造 DOI。

## 数据

主人给了原始数据就按真实值算；没有就明确写「示例数据」并给生成脚本，不冒充实测。

```python
import numpy as np, pandas as pd
rng = np.random.default_rng(42)
df = pd.DataFrame({
    "group": np.repeat(["A","B"], 50),
    "score": np.r_[rng.normal(72, 8, 50), rng.normal(79, 7, 50)],
})
from scipy import stats
print(stats.ttest_ind(df[df.group=="A"].score, df[df.group=="B"].score))
```

图表：`matplotlib` 出 PDF 矢量图，字号 ≥ 8pt，中文用 `SimHei`，图注在图下方。

## 降重

同义替换 + 语序调整 + 长句拆短 + 主动被动互换。不改变数据和结论。整段照搬要重写，不是换词。
